= Determine se uma atualização de sistema é recomendada para o seu sistema de storage no Digital Advisor
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Se você deseja identificar se uma atualização do sistema é recomendada para o seu contrato de suporte técnico ou hardware, pode usar a opção de atualização do sistema.

Você pode acessar esse recurso por meio do Lifecycle planning (*Storage* > *Lifecycle planning*) ou por meio do Digital Advisor (*Dashboard > Planning widget > System Refresh*).

Para obter mais informações sobre esse recurso, consulte link:https://docs.netapp.com/us-en/console-lifecycle-planning/use/tech-refresh.html["Avalie uma atualização do sistema"] na documentação do Console.
