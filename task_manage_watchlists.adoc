= Gerencie uma lista de observação no Digital Advisor.
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Você pode exibir o painel de diferentes listas de observação, editar os detalhes de uma lista de observação existente e excluir uma lista de observação.

.Passos
. No painel esquerdo, selecione *Watchlists*.
+
É apresentado o ecrã *Manage Watchlist* (gerir lista de vigias).

. Selecione o nome da lista de observação para visualizar os detalhes da lista de observação no painel de controle.
. Selecione *Editar* para atualizar os detalhes da watchlist.
. Selecione *Excluir* para excluir a watchlist.
